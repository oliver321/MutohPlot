# v0.0.10

- The CLI displays the installed package version in `mutohplot --help` and
  provides `mutohplot --version`.
- HP-GL input supports absolute and relative arcs (`AA`, `AR`) and circles
  (`CI`) through deterministic polyline approximation.
- The original `examples/libtest.hpgl` file is included as a regression fixture.
- `--stats` reports both the input bounds and the transformed `first`/`second`
  output bounds, making unsafe page transformations visible before plotting.

For the included landscape A3 sample rotated onto portrait A3 and centred on
its drawing bounds:

```bash
mutohplot hpgl \
  examples/libtest.hpgl \
  libtest_a3_centered.hpgl \
  --offset-first -199.625 \
  --offset-second -135.875 \
  --stats
```

The expected output bounds are approximately `first=-199.62..199.62 mm` and
`second=-135.88..135.88 mm`.
