# v0.0.16

- HP-GL labels support `SL` character slant and `CP` character-space movement.
- Edge rectangles (`EA`) and filled rectangles (`RA`) are converted.
- `RA` fill spacing accounts for the selected pen width and the scale applied
  by `--fit`.
- Compact numeric HP-GL command streams are parsed without requiring a
  semicolon before the next command.
- MutohPlot loads the required packaged `Standard.toml` pen profile.
- Pen profiles describe groups, widths, colours, types, and optional speed
  values. A different complete profile can be selected with `--config`.
- The standard XP-500 profile groups pens 1 and 2 as 0.5 mm pencils and pens 3
  and 4 as 0.3 mm pencils.

The release was validated with 111 automated tests, successful GitHub CI,
preview inspection, Raspberry Pi installation and conversion tests, and an A3
hardware plot on the Mutoh XP-500.
