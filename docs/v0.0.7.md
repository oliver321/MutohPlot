# MutohPlot v0.0.7

A3 is now the default paper format for SVG conversion and hardware testing.

## Calibration

```bash
mutohplot calibrate calibration_a3.hpgl   --window norm   --margin 5   --preview calibration_a3_preview.svg   --report
```

The calibration drawing contains:

- physical A3 paper outline
- selected hard-clip outline
- optional safety-area outline
- paper-centre and hard-clip-centre crosses
- 50, 100 and 200 mm measuring bars
- boundary corner and midpoint marks

## Safety report

Use `--report` for a transformation and bounds report. Use `--strict-bounds`
to abort SVG conversion when any geometry lies outside the selected drawable area.
