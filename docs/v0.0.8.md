# v0.0.8 – automatic hard-clip centre correction

Measured A3 Norm margins from v0.0.7:

- top: 46 mm
- bottom: 5 mm
- left: 15 mm
- right: 16 mm

The vertical result showed that output was about 10 mm too low. v0.0.8 now
calculates the correction from the selected hard-clip margins:

    first correction = -(top - bottom) / 2
    second correction = -(left - right) / 2

The correction is applied to SVG conversion and calibration output.

Use `--no-hardclip-correction` to reproduce the old behaviour.
